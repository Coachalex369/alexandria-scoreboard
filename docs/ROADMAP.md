# Roadmap

Planned directions. None of this is a commitment or a schedule.

- **Signed Windows releases** published on the Releases page, with checksums.
- **Second-monitor and compact widget polish** for the desktop app.
- **macOS and Linux** builds of the desktop app (the browser version already runs wherever Node 22 runs).
- **More event sources**: statusline and OpenTelemetry data where they add information the hooks do not give, and
  adapters for other coding agents.
- **Better estimates**: more calibration history, per-task-type ranges, and published evaluation results as the
  evaluation harness (`tools/sb-eval.js`) accumulates runs.
- **Test results without manual marks** through the collector, and a daily rollover for long-running sessions.
- **Accessibility and localisation** of the board.

Issues and suggestions are welcome.
